# Pocket Hawk-Eye (working name: pocketeye)

Cricket ball-tracking for home, terrace and ground cricket using a single phone camera.
It measures speed, swing, turn, line & length, bounce height, wicket prediction and (approximate) shot power.
It runs on Windows and Android.

Status: **planning.** See [docs/PLAN.md](docs/PLAN.md) for the proposed architecture, accuracy estimates, folder structure and build order.
